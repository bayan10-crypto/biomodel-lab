# Биомодель зертханасы

«Биологияда теориялық модельдеу әдісін қолданудың тиімділігі» тақырыбындағы магистрлік диссертацияның тәжірибелік бөліміне арналған виртуалды зертхана.

- **Білім беру бағдарламасы:** 7М01505 – Биология мұғалімдерін даярлау
- **Орындаған:** Г.Т. Науырызбай
- **Ғылыми жетекшісі:** б.ғ.к., қауымдастырылған профессор Г.Т. Картбаева
- **Университет:** Академик Е.А. Бөкетов атындағы Қарағанды ұлттық зерттеу университеті

## Мазмұны

8-сыныптың 3-тоқсанындағы 16 тақырып. Әр тақырыпта:

- шашып, қайта жинауға болатын екі интерактивті 3D модель;
- әр бөлшек туралы ақпарат;
- тест, реттілік және сәйкестендіру тапсырмалары;
- 10 дескрипторлық бағалау парағы (бір дескриптор – 1 балл);
- кейбір тақырыптарда «Суреттегі сандарды ата» қосымша тапсырмасы.

## Іске қосу

Сайт бір ғана `index.html` файлынан тұрады. Оны браузерде ашу жеткілікті, ешқандай орнату қажет емес.

**GitHub Pages арқылы жариялау:** репозиторийдің Settings → Pages бөлімінде Source ретінде `main` тармағын және `/ (root)` қалтасын таңдаңыз. Бірнеше минуттан кейін сайт `https://<аккаунт>.github.io/<репозиторий>/` мекенжайында ашылады.

ЖИ көмекші тек claude.ai ішінде жұмыс істейді. GitHub Pages-те оның батырмасы көрінбейді, сайттың қалған бөлігі толық жұмыс істейді.
